# DR-002：采用仓库原生研究记忆

- 日期：2026-08-16
- 状态：`ACCEPTED`
- 决策类型：研究管理
- 研究方法影响：无

## 决策

新Codex项目以 `docs/memory/**` 作为副线长期上下文入口，并通过Git版本管理。暂不安装社区agentMemory服务器或MCP服务。

## 理由

- 当前仓库没有 `.agentMemory`、Node项目或已审查的服务配置；
- 副线更需要可审阅、可回滚、与任务/证据绑定的记忆，而不是先引入运行时依赖；
- Markdown文件可以由任何新agent读取，也不会把主线全局记忆自动提升为权威事实；
- 若未来信息规模超过Markdown检索能力，可以在单独任务中评估搜索服务。

## 约束

- 研究设计 agent维护项目记忆；实验执行 agent只读。
- 实验结论必须先通过结果审查，再进入证据台账。
- 不保存完整聊天转录，不复制其他仓库的研究结论。
