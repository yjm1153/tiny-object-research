# DR-001：启用研究—实验双角色治理

- 日期：2026-08-16
- 状态：`ACCEPTED`
- 决策类型：项目治理
- 研究方法影响：无

## 背景

副线已经具备独立仓库、研究简述、任务/结果目录和首张基线任务卡，但仓库级规则尚未完整区分研究设计 agent 与实验执行 agent 的权限，也缺少独立审查、法定信号和固定 Git 同步点。

## 决策

建立与主线管理强度相近、内容完全独立的治理系统：

1. 研究设计 agent 负责问题、任务卡、设计审查、结果审查和下一任务放行；
2. 实验执行 agent 只执行已批准任务并回传证据，不得自我审批；
3. 任务、结果和研究审查使用独立模板和目录权限；
4. `EXPERIMENT_*` 与 `REVIEW_*` 信号严格分离；
5. 研究与实验使用不同分支，并在固定状态变化时提交/推送；
6. 未配置远端时明确记录 `REMOTE_NOT_CONFIGURED`，不伪造 PR 审查。

## 独立性边界

本决策只迁移管理范式，不迁移其他项目的研究问题、数据集、模型、实验ID、Gate、结论或代码状态。副线继续以2–8 px极小目标漏检和PRTiny为当前研究口径。

## 对现有 PRT-001 的影响

`codex/exp-prt-001` 保留现有任务卡提交。治理分支进入 `main` 后，该实验分支需要基于新 `main` 重建或rebase，并补充正式设计审查记录。完成该衔接前，不启动实现或训练。
