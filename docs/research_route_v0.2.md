## 1. 论文要回答的问题

有效尺寸 `sqrt(w*h)` 落在 `[2,8)` 的目标只有很少空间证据。研究浅层的两个环节：早期下采样是否可保留更多可用细节；随后能否利用局部空间与多频描述的一致性减少无效增强。P2 是载体，不算贡献；S2D、DCT、普通注意力也不单独算贡献。

候选贡献是“部分保留 + 有条件增强”在极小目标漏检中的可测增量及适用边界。没有实验证明前，不使用首创、因果确证、统计显著或高效等结论性表述。

## 3. 先实现一个可测试原型

```text
图像 → ResNet stem conv1 → PDD（单位置替换 maxpool）→ C2…C5
     → FPN P2…P6 → SSR（先仅 P2）→ 原 FCOS head
```

PDD 沿用 1:1 通道拆分、S2D / stride-2 DWConv、concat 后 1×1 压缩的原设计。当前代码只实现 stem 一个位置；前面的 stride-2 conv1 仍保留，所以不能声称恢复已丢失的输入信息。暂不改其初始化/冻结策略以掩盖旧异常。

SSR 原型选择（工程准入冻结，尚非正式训练方案）：

1. 输入 `X[B,C,H,W]`，1×1 投影到 `d=16` 得到 Z；无 BN，避免小 batch 的额外状态混杂。
2. 空间响应 `S=sigmoid(PW(DW3(Z)))`；残差值 `V=SiLU(DW3_value(Z))`，两者参数独立。
3. 每通道局部 4×4 正交 DCT，stride=2；按 `u+v≤1`、`2≤u+v≤3`、`u+v≥4` 分低/中/高频。每带系数平方取均值，除以三带之和加 epsilon，双线性对齐回 H×W，形成 3d 通道描述。
4. `F=sigmoid(PW(energy_low, energy_mid, energy_high))`；所有频带由数据学习，不预置“高频应增强”。
5. `G=S*F*(1-abs(S-F))`，`Y=X+alpha*PW_out(G*V)`，每通道 alpha 初值 0.001。该公式是待检验的一致性启发式，不是概率可靠性证明；关闭模块必须严格恒等。
6. DCT/能量在 FP32 中运算；小图/奇数图使用右下 replicate padding；DCT 无学习参数。只在高分辨率 P2 增强，其余金字塔输出保持原值。

本次只执行合成输入前反向和优化器单步；检测器集成、AP 与速度均 `NOT_TESTED`。原型公式在正式训练前还需独立审查；不得由本 session 自己批准其结果。

## 4. 能否写论文的最小实验包

| 阶段 | 关键问题与对照 | 节奏 / 交付 |
|---|---|---|
| R0 基线恢复 | 核对原始标注 hash/计数、预训练加载率、精确冻结、BN、loss、正样本与预测分布 | 优先复查已有产物与一次小样本诊断；明确根因后才成对重跑，保持旧结果 |
| R1 PDD 去留 | 正常匹配 P2 对 PDD，遵守原 Gate 与灰区 seed2；通过后做 S2D-only、DW-only/容量匹配 | 两 seed 主比较；先淘汰无效候选，不为负结果叠加模块 |
| R2 SSR 机制 | P2、spatial-only、容量匹配 spatial-only、frequency-only、无一致性融合、完整 SSR、频谱空间错位 | pilot 筛选后，完整 SSR 与最强空间控制做两 seed；必须同时胜过无一致性与错位控制才能支持机制 |
| R3 组合 | P2、PDD、SSR、PDD+SSR 同协议 2×2 | 报告交互项 Δcombined−ΔPDD−ΔSSR；不强求协同，不能只报告组合好看结果 |
| R4 外部验证 | 优先 VisDrone 的基线/最终方法；预算允许再做 RTMDet-s-P2 | 两者至少先完成一个；两者均为投稿加分，不作为早期开发全部前置 |
| R5 投稿包 | 同 GPU 实测 latency/峰值显存/参数；主表、必要消融、分箱、代表成功/失败案例 | 无实测速度就不写加速；NWD 作为统一监督控制，单独任务，不计方法贡献 |

容量匹配 spatial-only：保留与 SSR 相同投影、门控和残差参数，把频谱输入替为 `[Z, avg3(Z), avg5(Z)]`。这是主公平控制；普通小空间分支仅是低成本参考。频谱错位在每个样本内循环平移频带描述，保留值分布并破坏空间对应，batch=1 也有效，不混入其他图像。

正式 R2/R3 数值阈值与训练预算在看到其结果前另卡冻结；本原型卡不授权这些 AP 运行。当前主任务仍是 PRT-002-A1 的问题关闭。

## 5. 投入与停止

优先保留一个有稳定收益、解释清楚的贡献。若 SSR 不胜过容量匹配空间控制，放弃频谱增益主张；PDD 不过匹配 Gate 就删除该候选，不因故事完整强留两个模块。任何主架构改变仍需版本化决策与用户确认。
