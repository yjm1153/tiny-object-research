# 实验交接区约束

- `tasks/` 由研究设计 agent 维护，制定明确的中长期阶段目标、假设与 Gate；实验执行 agent 只读。
- `results/` 由实验执行 agent 按模板新建结果与自查报告；不得修改他人的既有报告。
- 阶段任务首次正式运行后科学变量冻结；非科学变量的工程调优由实验 agent 自主闭环并记录于报告中。
- 同一任务重跑使用 `<TASK-ID>-rerun-N.md`，不得覆盖失败或较差结果。
- 原始日志、checkpoint 和大型指标留在 `outputs/<TASK-ID>/`，交接区只保存可审阅文本、自我审查清单与轻量证据索引。
- 禁止在本目录保存研究路线副本、聊天记录、长期记忆、数据集或权重。
